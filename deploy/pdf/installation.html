Darts – Installation auf dem Server

Kurzanleitung für Docker · Version {{VERSION}}

Darts besteht aus einer Web-App (iPhone, iPad, Browser) und einem kleinen Vermittlungs-Server, über den die Handys online miteinander spielen. Spielstände und Statistiken liegen nur auf den Geräten – auf dem Server wird nichts gespeichert. Er braucht ca. 30–60 MB RAM.

Was du vorher brauchst

  • Linux-Server mit Docker und docker compose (v2)
  • eine (Sub-)Domain, z. B. darts.deinedomain.de, mit einem A-Eintrag auf die IP des Servers
  • Ports 80 und 443 von außen erreichbar (Firewall / Router-Weiterleitung) und nicht von einem anderen Webserver belegt
Läuft auf dem Server schon nginx, Traefik, Nginx Proxy Manager o. Ä. auf Port 80/443? Dann nicht diese Kurzanleitung, sondern Weg A2b in ANLEITUNG_HOSTING.md nehmen.

1ZIP auf den Server kopieren

scp darts_server_{{VERSION}}.zip benutzer@server:~

2Entpacken und installieren

unzip darts_server_{{VERSION}}.zip
cd darts_server_{{VERSION}}
bash install.sh

Das Skript fragt nach der Domain und erledigt den Rest:

  1. prüft Docker, DNS und die Ports 80/443,
  2. legt die Einstellungen .env an,
  3. startet die Container darts (Server) und caddy (HTTPS-Zertifikat von Let's Encrypt, wird automatisch erneuert),
  4. prüft am Ende, ob https://<domain> erreichbar ist.
Erscheint „Fertig! Darts läuft unter https://…“, ist alles erledigt. Die Container starten nach einem Neustart des Servers von selbst.

3Spieler einrichten

AndroidAuf dem Handy https://<domain>/app öffnen → „Android-App herunterladen“ → installieren → zurück auf die Seite und „App mit diesem Server verbinden“ tippen. Fertig.
iPhone / iPadhttps://<domain> in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
Computerhttps://<domain> im Browser öffnen.

Update (neue Version von Simon)

unzip darts_server_<neu>.zip
cd darts_server_<neu>
bash install.sh

Einstellungen und Zertifikat werden automatisch übernommen. Die Apps melden die neue Version danach von selbst. Den alten Ordner kannst du anschließend löschen. Zurück zur alten Version: in den alten Ordner wechseln und dort bash install.sh starten.

Nützliche Befehle

bash install.sh statusLäuft alles? (Container + HTTPS-Prüfung)
bash install.sh logsLogs ansehen (Strg+C beendet)
bash install.sh stopDarts anhalten
bash install.shwieder starten

Wenn etwas klemmt

„Port 80/443 schon belegt“Ein anderer Webserver läuft → Weg A2b in ANLEITUNG_HOSTING.md.
HTTPS antwortet nichtMeist zeigt die Domain noch nicht auf den Server (DNS braucht manchmal bis zu einer Stunde) oder Port 80/443 ist nicht freigegeben. bash install.sh logs zeigt, was Caddy meldet.
„Kein Zugriff auf Docker“sudo bash install.sh
Android: „App nicht installiert“Im Browser erlauben, Apps zu installieren (fragt Android beim ersten Mal).

Datenschutz & Sicherheit

  • Der Server speichert keine Spieler, Namen oder Spielstände – er reicht nur Nachrichten zwischen den Geräten weiter.
  • Der Container läuft ohne Root-Rechte, mit nur lesbarem Dateisystem und begrenztem Speicher (256 MB).
  • Von außen ist nur HTTPS über Caddy erreichbar.

Ausführliche Anleitung (anderer Webserver, ohne Docker, alle Einstellungen): ANLEITUNG_HOSTING.md im selben Ordner.
